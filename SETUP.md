# Priyansh10ff interactive profile

## What is interactive?

The GitHub README uses animated SVGs and clickable links, which GitHub supports.
The real 3D/WebGL controls live in `/studio`, deployed with GitHub Pages.

## Setup

1. Put these files in your `priyansh10ff` profile repository.
2. Push to `main`.
3. GitHub -> Settings -> Pages -> Source: GitHub Actions.
4. Open `https://priyansh10ff.github.io/priyansh10ff/`.
5. The README links visitors to the live interactive version.
